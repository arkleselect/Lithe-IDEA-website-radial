# Lithe Website

独立于 Lithe-IDEA 主工程的纯静态官网，使用 Astro 构建。

## 本地开发

```bash
pnpm install
pnpm dev
# pnpm dev --host 127.0.0.1
```

## 构建

```bash
pnpm build
pnpm preview
```

## 设计方向

Swiss / International + 工具感细节。以 4px 间距体系、8px 内圆角、低对比度边框和真实 IDE 截图为基础；不使用大面积模板化渐变或嵌套卡片。
